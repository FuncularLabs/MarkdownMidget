# Inline line breaks

In a paragraph: line one<br>line two.

Self-closing forms: alpha<br/>beta, and gamma<br />delta.

A backslash hard break before a br:\
<br>after the break.

A plain line ending before a br
<br>after it.

| Cell | With a break    |
| ---- | --------------- |
| a    | one<br>two      |
| b    | three<br />four |

- list item one<br>continued
- list item two<br/>continued

> quoted line<br />still quoted

The next paragraph is an empty-line marker that earlier saves wrote:

<br />

Paragraph after the marker.
