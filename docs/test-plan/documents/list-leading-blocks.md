# List items that start with a block

A quote:

- > quoted text

An ordered item with a quote:

1. > quoted text

A code fence:

- ```js
  code in a list item
  ```

A heading:

- # heading in a list item

A table:

- | a | b |
  | - | - |
  | 1 | 2 |

A rule:

- ***

A nested list straight away:

- - nested

A quote, then a paragraph in the same item:

- > quote

  paragraph after the quote

Inside a quote:

> - > a quote in a list item in a quote

Task items keep their checkboxes:

- [ ] a task item
- [x] a done task item
